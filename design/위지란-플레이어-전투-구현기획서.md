# 위지란 플레이어 전투 구현 기획서

작성일: 2026년 10월 14일. 대상: Godot 프로젝트를 구현하는 Claude. 기준 프로젝트: `godot/`.

위지란은 경공으로 위치를 잡고, 흑월장으로 내상을 쌓고, 패링으로 적의 공세를 끊어 만월을 적중시키는 근접 플레이어 캐릭터다. 이 문서는 입력, 상태 전이, 피해 계산, 보스 기절, 자원과 검증 조건을 정의한다. 게임 코드 변경은 별도 구현 작업이며, 아래 신규 수치는 첫 플레이테스트용 기준값이다. 수치는 데이터로 분리해 조정하되 판정 규칙은 임의로 바꾸지 않는다.

## 1 구현 범위와 기존 코드 연결

사용자 확정 요구는 기존 이동·달리기·대시·점프·앉기·기본 공격 활용, 2단 점프, 스페이스바 패링, 부분 패링의 피해 감소, 완전 패링의 피해 0과 보스 기절 수치 증가다. 그 외 아래 내용은 이를 플레이 가능한 전투로 연결하는 기본 설계다.

| 현재 파일 | 확인한 구조 | 구현 시 처리 |
|---|---|---|
| `godot/scripts/player.gd` | CharacterBody2D, ATTACKS 5종, stage·time·queued, 이동과 공격 | 기존 이동 감각과 공격 클립 유지. 피격·패링·자원·공중 재도약 추가 |
| `godot/scripts/main.gd` | 런타임 InputMap, HUD, 훈련장과 selftest | Space 점프 제거, parry 추가, 전투 HUD와 공격 훈련 적 추가 |
| `godot/scripts/dummy.gd` | HP 100, take_hit, 자동 재생성 | 공통 피격 결과를 수신하고 내상 초기화. 공격 적과 별개로 유지 |
| `godot/scripts/juice.gd` | Juice.frozen 기반 히트스톱과 타격 연출 | 기존 방식 확장. Engine.time_scale 사용 금지 |
| `godot/scripts/anim_data.gd` | manifest 기반 클립·슬롯 | 신규 연출도 클립명으로 연결. 슬롯 번호 하드코딩 금지 |
| `godot/project.godot` | 640×360 뷰포트, 물리 120Hz | 거리 단위는 뷰포트 px. 시간 판정은 초 단위 |

기존 지상 공격 1·2·3을 초승·반월·만월로 명명한다. 기존 코드의 흑월장·흑월회천·천흑낙장 표시명만 바꾸고, attack1·attack2·attack3 클립과 기본 타이밍은 보존한다. 공중 낙장과 하단 장법도 유지한다. 웹 프로토타입 `output/`은 이번 구현 대상으로 삼지 않는다.

## 2 조작과 입력 처리

| 입력 | InputMap 액션 | 동작 |
|---|---|---|
| A / D, 좌우 방향키 | move_left / move_right | 기본 달리기 |
| Ctrl 유지 | walk | 걷기 |
| S 유지 | crouch | 지상 앉기·앉아 이동 |
| W 누르기 | jump | 지상 점프 / 공중 2단 점프 |
| Shift 누르기 | dash | 잔월보 |
| Space 누르기 | parry | 패링 1회 시도 |
| 좌클릭 / J / X | attack / attack_key | 기본 장법, 지상 연계, 공중·하단 공격 |
| 우클릭 / E | heavy_attack | 단독 강화 만월 |
| Q | ultimate | 월식 |
| R | reset | 훈련장 초기화 전용 |

Space는 jump 액션에서 반드시 제거한다. InputMap 재구성 시 기존 키 이벤트를 정리하여 중복 등록하지 않는다. 패링·공격·월식은 키를 누른 순간만 발동하고 OS 키 반복 이벤트는 무시한다. Space 유지로 자동 재패링이나 지속 방어는 발생하지 않는다. 재패링은 키를 놓고 다시 눌러야 한다.

마우스 공격은 기존처럼 커서의 좌우 위치로 공격 방향을 정한다. 키보드 공격은 좌우 입력이 있으면 해당 방향, 없으면 현재 바라보는 방향이다. 패링은 시작 시 좌우 입력을 우선하고, 없으면 현재 방향을 고정한다. 패링 중 마우스로 방향이 바뀌지 않는다.

같은 물리 틱의 새 행동 우선순위는 `패링 > 대시 > 월식 > 강화 만월 > 점프 > 기본 공격`이다. 조건을 만족해 실제 시작한 행동 하나만 채택하고 나머지 같은 틱 입력은 버린다. 자원 부족 등으로 상위 행동이 거절되면 다음 입력을 평가한다. 이동·걷기·앉기 유지 입력은 별도로 읽는다.

기존 점프 버퍼 0.14초와 코요테 0.085초를 유지한다. 패링은 정상 진행 중에는 선입력 버퍼가 없다. 취소 불가능한 공격 중 누른 Space는 저장하지 않고 실패한다. 패링이 뒤늦게 자동 발동하는 일을 막기 위한 규칙이다.

히트스톱 중에는 입력 요청만 보관하고 상태를 시작하지 않는다. 해제 첫 틱에 현재 상태의 실행 조건을 재검사한다. 같은 종류는 한 번만 보관하며 입력 우선순위는 위와 같다. 점프 버퍼 수명도 히트스톱 동안 줄지 않는다. 기존 기본 공격 연타 예약은 유지하되 서로 다른 입력 소스가 같은 틱에 들어와도 1회로 합친다.

## 3 플레이어 상태와 취소

지상·공중 여부는 물리 상태로 따로 관리하고, 행동 상태는 다음 중 정확히 하나다. stage는 ATTACK 안에서만 유효하며 상태와 독립적으로 공격을 계속하지 않는다.

| 행동 상태 | 이동과 가능한 전이 |
|---|---|
| FREE | 걷기·달리기·앉기·점프·대시·패링·공격. 월식과 강화 만월은 지상에서만 |
| ATTACK | 기존 전진량 사용. 공격별 cancel 시각 이후 이동·점프·대시·패링으로 취소 가능 |
| DASH | 기존 대시 속도·시간 유지. 중간 취소 불가. 기본 공격 예약만 허용 |
| PARRY | 전후반 판정 및 실패 회수. 성공하면 별도 성공 회수로 전이 |
| PARRY_RECOVERY | 성공 후 회수. 종료 시 FREE. 공격·점프·대시 예약 없음 |
| ULTIMATE | 월식 준비·발동·회수. 이동 및 다른 행동 취소 불가 |
| HURT | 피해 경직. 다른 행동 불가. 경직 종료 시 FREE |
| DEAD | 입력·공격·자원 회복 중단. 초기화나 부활로만 해제 |

기존 기본 공격 취소 시각은 1타 0.20초, 2타 0.22초, 3타 0.50초, 공중 0.20초, 하단 0.22초다. 취소는 시각 이상부터 허용한다. 패링 취소에 별도의 무조건 취소 권한을 주지 않는다. 강화 만월은 아래 표의 회수 증가만큼 종료와 취소 시각을 모두 늦춘다.

ATTACK에서 패링·점프·대시로 전이하면 queued, dash_clicks, 공격 판정, 모으기 이펙트를 정리한다. 같은 틱에 연계 예약과 패링이 경쟁하면, 취소 시각에 도달한 패링이 우선한다. 새 상태는 공격 시간을 0으로 시작한다. 착지만으로 패링이나 월식 상태를 해제하지 않는다.

## 4 허공답월과 이동

기존 RUN_SPEED 270, WALK_SPEED 95, CROUCH_SPEED 62, JUMP_SPEED 380, 대시 0.282초와 재사용 0.50초를 유지한다.

공중 재도약은 `air_jump_available` 불리언으로 관리한다. 지상에서 이륙한 뒤 착지까지 한 번만 사용할 수 있다.

1. 실제 바닥에 착지하면 air_jump_available을 true로 복구한다. 벽·천장 접촉으로는 복구하지 않는다.
2. 바닥 또는 코요테 시간 안의 W는 지상 점프다. 공중 재도약 권한을 소모하지 않고 코요테를 즉시 0으로 만든다.
3. 그 외 공중에서 W를 새로 누르면 재도약 권한을 검사한다. 허용 상태라면 권한을 소모하고 velocity.y를 -340 px/s로 덮어쓴다. 기존 상승 속도에 더하지 않는다.
4. 방향 입력이 있으면 velocity.x를 입력 방향 × 220 px/s로 설정하고 바라보는 방향도 변경한다. 없으면 현재 수평 속도를 유지한다.
5. 재도약에도 W 조기 해제에 따른 기존 JUMP_CUT 130을 적용한다. W 유지 한 번으로 두 번 뛰지 않는다.
6. 절벽에서 걸어 떨어져 코요테가 끝났어도 공중 재도약 한 번은 가능하다. 지상 점프까지 소급 제공하지 않는다.
7. 대시·패링·피격 중에는 재도약 불가. 공격 중에는 해당 공격의 cancel 시각 이후 가능하다. 피격이나 패링 성공으로 재도약 권한을 복구하지 않는다.

기존 공중 낙장의 하강 동작은 유지한다. 이번 버전에서는 공중 공격의 부유 효과나 적을 밟는 점프 초기화를 넣지 않는다. 비용은 없으며 발밑 반월 효과와 잔상으로 2단 점프를 구분한다.

## 5 Space 패링

### 5.1 패링 시도 시간표

패링 시작 시각을 t=0으로 잡는다. 모든 구간은 시작 포함·끝 제외다. 준비 지연 없이 시작 틱부터 판정한다.

| 경과 시간 | 판정 | 피격 결과 |
|---|---|---|
| 0.000 ≤ t < 0.100초 | 완전 패링 창 | 적격 공격의 피해 0, 부가 상태이상 0, 보스 기절 수치 증가 |
| 0.100 ≤ t < 0.250초 | 부분 패링 창 | 적격 공격의 최종 피해 70% 감소, 짧은 밀림 |
| 0.250 ≤ t < 0.450초 | 실패 회수 | 방어 판정 없음. 피격 시 정상 피해 |
| t ≥ 0.450초 | 종료 | FREE 복귀 |

120Hz 기준 완전 창은 12틱, 부분 창은 18틱, 실패 회수는 24틱이다. 판정은 애니메이션 프레임이 아니라 combat time으로 계산한다. 0.100초의 공격은 부분 패링, 0.250초의 공격은 정상 피격이다.

패링은 지상·공중에서 가능하며 내공을 소모하지 않는다. 지상에서는 수평 이동을 제동하고, 공중에서는 시작 수평 속도의 50%를 유지하되 중력은 계속 적용한다. 패링 중 방향 전환·앉기·공격·점프·대시는 불가하다. 같은 시도의 판정 창은 한 번의 성공만 처리하고 닫는다.

성공하면 원래 0.45초 시간표를 종료하고 완전 성공 회수 0.10초, 부분 성공 회수 0.18초로 전이한다. 회수 중 입력으로 시간을 갱신하지 않는다. 성공 회수 종료 후 새 Space 입력으로 다시 패링할 수 있다. 별도의 중복 쿨다운은 두지 않는다.

### 5.2 공격 적격 조건

패링은 적 공격 판정과 플레이어 피격 상자가 실제로 겹칠 때만 평가한다. 주변에 적이 있다는 이유로 성공하지 않는다.

공격 데이터의 parry_class를 사용한다.

| 분류 | 완전 창 | 부분 창 | 예시 |
|---|---|---|---|
| NORMAL | 완전 | 부분 | 검격, 창 찌르기, 일반 화살 |
| PERFECT_ONLY | 완전 | 정상 피격 | 강한 내려찍기. 별도 색과 아이콘으로 예고 |
| UNPARRYABLE | 정상 피격 | 정상 피격 | 잡기, 지면 장판, 낙하·환경 피해 |

방향 판정은 `incoming_origin`에서 플레이어 몸통 중심을 뺀 벡터와 고정된 facing의 내적이 0 이상인지 검사한다. 앞쪽 반평면만 막는다. origin은 근접 공격의 해당 타격 발생점, 투사체는 직전 위치로 정한다. 정확히 겹쳐 벡터가 0이면 공격 진행 방향의 반대를 사용한다. 그 방향도 없으면 패링 불가로 처리한다. 적이 이동해 등 뒤로 넘어가도 옛 적 위치로 앞뒤를 판정하지 않는다.

패링 가능한 투사체는 성공 등급과 무관하게 제거한다. 반사는 이번 범위에 없다. 환경 피해와 잡기는 대시 무적 및 성공 후 보호도 무시하는 별도 플래그를 가질 수 있다. 해당 예고와 테스트를 반드시 제공한다.

### 5.3 성공과 실패 결과

| 항목 | 완전 패링 | 부분 패링 | 실패 |
|---|---|---|---|
| HP 피해 | 정확히 0 | 방어 적용 후 피해의 30% | 방어 적용 후 피해 100% |
| 플레이어 피격 경직 | 없음 | 별도 HURT 대신 성공 회수 0.18초 | 공격 hitstun 적용 |
| 밀림 | 없음 | 공격 knockback의 25% | 100% |
| 공격의 신규 상태이상 | 차단 | 원래 규칙대로 적용 | 원래 규칙대로 적용 |
| 내공 | 10 회복 | 변화 없음 | 변화 없음 |
| 마열 | 10 감소 | 변화 없음 | 변화 없음 |
| 월식 게이지 | 12 증가 | 변화 없음 | 변화 없음 |
| 적 기절 게이지 | posture_damage 적용, 기본 25 | 0 | 0 |
| 일반 적 반응 | 현재 공격 중단, 0.30초 반동 | 공격 유지 | 공격 유지 |

완전 패링의 보스 공격은 기절 임계치를 넘기기 전까지 중단하지 않는다. 따라서 보스 연속 공격은 계속될 수 있다. 일반 적 슈퍼아머도 posture 게이지를 쓰도록 설정하면 같은 규칙을 적용한다.

완전 성공 후 일반 공격에 대한 보호 시간은 0.06초, 부분 성공 후에는 0.12초다. 보호 시간은 성공 시점부터 계산하며 추가 성공이나 보상을 발생시키지 않는다. 이미 걸린 지속 피해는 완전 패링으로 해제되지 않으며 보호의 대상도 아니다. 부분 패링의 감소 피해로 HP가 0 이하가 되면 즉시 사망한다.

한 번의 패링으로 여러 적을 모두 막지 않는다. 동일 틱 여러 공격은 충돌 시각, 같은 시각이면 attack_instance_id 순서로 처리한다. 첫 적격 공격만 패링 성공 및 보상을 받는다. 뒤 공격은 성공 보호 시간 규칙으로 처리하며 기절 수치를 추가 지급하지 않는다. 지속 타격 판정의 재접촉도 보상을 반복 지급하지 않는다.

### 5.4 완전 패링 후 반격

완전 패링 성공 시 `counter_ready`를 1.20초 부여한다. 시간은 성공 회수 동안에도 진행한다. 다음 지상 초승을 시작할 때 소모하며, 해당 공격에만 반격 속성을 저장한다.

- 반격 초승은 기본 직접 피해 12를 유지하고, 내상을 기본 1 대신 2중첩 부여한다.
- 전진 속도는 초승 lunge 170의 1.25배로 설정한다. 순간이동이나 자동 추적은 없다.
- 공격이 빗나가거나 중간에 피격되어도 소비한 반격 권한은 반환하지 않는다.
- 기본 초승 외 공격 시작, 정상 피격, 부분 패링, 사망은 권한을 해제한다. 이동·점프·대시만으로는 해제하지 않는다.
- 완전 패링을 다시 성공하면 남은 시간을 1.20초로 갱신한다. 중첩하지 않는다.

대시는 아래 무적 기능만 제공하고 정밀 회피 보상을 별도로 주지 않는다. 반격 보상은 Space 완전 패링에 집중한다.

## 6 보스 기절 수치

보스마다 HP와 별개로 posture_current, posture_max를 가진다. 기절 수치는 채울수록 기절에 가까워지는 방식이다.

| 속성 | 첫 훈련 보스 기준 |
|---|---|
| posture_max | 100 |
| 일반 패링 가능 공격의 posture_damage | 25 |
| 큰 PERFECT_ONLY 공격의 posture_damage | 40 |
| 감소 시작 | 마지막 기절 수치 증가 후 3.0초 |
| 감소 속도 | 초당 10 |
| 기절 지속 | 2.50초 |
| 기절 종료 후 재기절 면역 | 1.0초 |

완전 패링만 기절 수치를 올린다. 기본 공격·내상 폭발·부분 패링·월식은 이번 버전에서 기절 수치를 올리지 않는다. 100 이상이면 기절을 한 번 발생시키고 수치를 0으로 초기화한다. 초과 수치는 다음 기절로 이월하지 않는다.

기절 진입 시 보스의 현재 행동·근접 히트박스·예약 타격을 취소한다. 이미 발사된 독립 투사체와 바닥 장판은 남는다. 보스 기절 중에도 HP 피해와 내상 부여·폭발은 정상 적용하지만 posture는 쌓이지 않는다. 기절 중 추가 타격으로 기절 시간을 연장하지 않는다. 기절에 추가 피해 배율은 없고 자유 공격 기회가 보상이다.

기절 종료 후 1초 동안 완전 패링의 피해 차단·자원 보상·반격 권한은 정상 동작하지만 posture 증가만 막는다. 보스 페이즈 전환은 기절을 종료하고 posture와 적에게 남은 내상을 초기화한다. 전환 무적 중에는 피해·내상·게이지 획득을 모두 막는다.

## 7 공통 피격과 대시 무적

플레이어 초기 최대 HP는 100이며 자동 HP 회복은 없다. 무간심법의 빠른 회복은 내공 회복을 뜻한다.

잔월보는 기존 0.282초 이동을 유지하고, 시작 후 `[0.040, 0.180)`초에 일반 공격 무적을 부여한다. 시작과 종료 구간은 피격 가능하다. 대시 무적은 패링 보상과 보스 기절 수치를 주지 않는다. 대시 중 공중 점프 횟수는 초기화되지 않는다.

피격 처리 순서는 다음과 같다.

1. 죽은 대상·무효 공격·이미 처리한 타격 ID를 제외한다.
2. 전환 무적·대시 무적·피격 후 보호를 검사한다. ignore_invulnerability 플래그의 피해는 통과한다.
3. 보호에 막히지 않았다면 패링 상태·창·방향·parry_class를 검사한다.
4. 방어율과 패링 등급에 따라 피해를 계산한다.
5. HP·신규 상태이상·밀림·피격 상태를 반영한다. 사망이 다른 상태보다 우선한다.
6. 완전 성공이면 보상과 공격자 posture를 반영한다. 이 타격 이벤트를 처리 완료로 기록한다.

일반 피격은 기본 경직 0.25초와 일반 공격 보호 0.35초를 적용한다. 공격 데이터로 경직은 변경할 수 있지만 보호는 플레이어 공통값이다. 보호에 막힌 타격도 그 타격 ID를 처리 완료로 기록하여 같은 지속 히트박스가 보호 종료 직후 다시 때리지 않게 한다. 다단 공격은 각 타격마다 별도 hit_id를 발행한다.

부분 패링의 성공 회수는 중력과 25% 밀림을 적용하며, 부분 패링 전용 보호 0.12초를 사용한다. 완전 패링도 중력은 멈추지 않는다. 피격 시 공격·예약·반격 권한·모으기 이펙트는 정리하되 소모 자원을 반환하지 않는다.

### 피해 계산식

armor_rate는 0~0.80으로 제한한다. 모든 피해는 마지막에 한 번만 반올림하고, 0보다 큰 원시 피해의 최종값은 최소 1이다. 단 완전 패링·무적·공격 무효는 최소 피해 규칙보다 우선하여 정확히 0이다.

```text
direct = raw_direct_damage * (1 - armor_rate)
internal = raw_internal_damage * (1 - armor_rate * 0.25)
normal_damage = direct + internal
partial_damage = normal_damage * 0.30
perfect_damage = 0
final_damage = floor(selected_damage + 0.5)  # 양수인 경우 최소 1
```

예: 원시 피해 40, 방어율 0.25인 공격은 정상 피해 30, 부분 패링 피해 9, 완전 패링 피해 0이다. 독·장판 같은 별도 지속 피해 틱은 새 공격 이벤트이며 패링 가능한 공격에 섞어 자동으로 차단하지 않는다.

## 8 흑월장과 내상

내상은 적별 0~3중첩, 마지막 부여 후 6.0초 유지다. 중첩별 타이머 대신 하나의 만료 시간을 사용한다. 최대 중첩에 다시 부여해도 6초로 갱신한다. 만료 시 전부 사라지고, 적 사망·재생성·페이즈 전환에도 초기화한다.

| 공격 | 직접 피해 | 내상 | 내공 비용 | 마열 |
|---|---:|---|---:|---:|
| 초승, 기본 1타 | 12 | 적중 시 +1 | 0 | 0 |
| 반월, 기본 2타 | 18 | 적중한 적 각각 +1 | 0 | 0 |
| 만월, 기본 3타 | 30 | 기존 중첩 전부 폭발 | 0 | 0 |
| 공중 낙장 | 15 | +1 | 0 | 0 |
| 하단 장법 | 10 | +1 | 0 | 0 |
| 반격 초승 | 12 | 기본 1 대신 +2 | 0 | 0 |
| 강화 만월, E / 우클릭 | 42 | 기존 중첩 전부 강화 폭발 | 25 | +30 |

기본 공격의 직접 피해·사거리·타이밍은 현재 ATTACKS와 같다. 반월은 기존 전방 판정 내 여러 적을 공격하며 후방 판정을 새로 추가하지 않는다. 적에게 실제 피해가 적용된 경우에만 내상 부여·소모와 게이지 획득이 일어난다. 공격을 막거나 무적으로 무효화한 적에게 내상을 넣지 않는다.

기본 만월의 내부 원시 피해는 `소모 중첩 × 8`, 강화 만월은 `소모 중첩 × 12`다. 내상이 0이어도 직접 피해는 정상이다. 만월은 내상을 추가하지 않는다. 직접 피해와 내부 피해는 하나의 결과로 합산해 반올림하고 피해 숫자도 합계 한 번만 표시한다. 적중 직전 중첩을 읽어 폭발을 계산하고 같은 처리에서 중첩을 0으로 만든다.

강화 만월은 지상 FREE 상태에서만 시작할 수 있다. 기본 콤보 중에는 새 강화 만월로 취소하지 않는다. attack3 클립·기본 사거리 100·판정 `[0.22, 0.31)`초·기본 종료 0.76초를 재사용하고 기본 회수에 0.10초를 추가한다. 따라서 평상시 강화 만월 종료는 0.86초, 취소 가능 시각은 0.60초다. 추가 시간은 마지막 회수 포즈를 유지한다. 일반 3타를 자동 강화하지 않는다.

### 내상 계산 예

방어율 0.50인 기사에게 내상 3중첩을 일반 만월로 폭발시킨다.

```text
직접 피해 = 30 × 0.50 = 15
내부 피해 = (3 × 8) × (1 - 0.50 × 0.25) = 21
합계 = 36, 처리 후 내상 = 0
```

장갑이 없는 적에게는 54다. 갑옷은 직접 피해를 크게 줄이지만 내상에는 약하게 작용한다.

## 9 무간심법과 마열

내공은 0~100, 초기 100, 살아 있는 동안 초당 20 회복한다. 공격·이동·공중·피격·월식 회수 중에도 회복하며 히트스톱·일시정지·사망 중에는 멈춘다. 내공 부족 시 강화 만월·월식은 시작하지 않고 자원 부족 표시만 출력한다. 다른 공격으로 자동 대체하지 않는다.

마열은 0~100, 초기 0이다. 마열을 올리는 기술을 시작한 후 1.5초 동안 자연 감소하지 않고, 이후 초당 12 감소한다. 기본 공격을 해도 감소 대기 시간을 갱신하지 않는다. 완전 패링의 마열 -10은 대기 중에도 즉시 적용한다.

| 상태 | 진입 조건 | 효과 |
|---|---|---|
| 평상 | 침식이 아니며 마열 < 50 | 기본 성능 |
| 과열 | 침식이 아니며 마열 ≥ 50 | 강화 만월의 내부 피해만 ×1.20 |
| 침식 | 마열 ≥ 85에 도달 | 과열 배율 유지, 강화 만월의 회수에 추가 0.15초 |

침식은 마열이 60 이하가 되어야 해제한다. 해제 후 50 이상이면 과열, 50 미만이면 평상이다. 침식 추가 회수는 종료와 취소 시각에 모두 더한다. 침식 상태 강화 만월은 종료 1.01초, 취소 0.75초가 된다. 판정 시작과 종료는 늦추지 않는다.

강화 만월 시작 시 기존 마열로 공격 배율과 회수 증가를 먼저 확정한 뒤 내공과 마열을 지불한다. 이 공격으로 새로 침식에 들어가도 이번 공격의 확정된 회수는 바꾸지 않는다. 공격 도중 마열 감소·패링 등으로 배율을 다시 계산하지 않는다. 이는 attack snapshot에 저장한다.

마열이 100이어도 내공이 충분하면 강화 만월을 쓸 수 있다. 수치는 100에서 제한하고 자연 감소 대기는 갱신한다. 침식은 HP를 자동 차감하거나 이동·점프·패링을 봉쇄하지 않는다. 위력과 후딜을 교환하는 선택이다.

## 10 월식

월식 게이지는 0~100, 초기 0이며 자연 회복하지 않는다. 기본 및 강화 장법이 적에게 양수 피해를 주면 공격 인스턴스당 4를 한 번 획득한다. 여러 적을 맞혀도 4이며, 내상 폭발은 같은 공격에 포함한다. 완전 패링은 성공당 12다. 월식 자체는 게이지를 생성하지 않는다.

| 항목 | 기준 |
|---|---|
| 발동 입력 | 지상 FREE에서 Q |
| 조건 | 내공 ≥ 60, 월식 게이지 100, 쿨다운 0, 수전증 아님 |
| 시작 비용 | 내공 60, 게이지 100, 마열 100으로 설정 |
| 쿨다운 | 시작부터 20초 |
| 준비 | 0.00~0.30초 |
| 폭발 | 0.30초 경계를 통과하는 틱에 1회 |
| 회수 | 폭발 후 0.55초, 총 0.85초 |
| 범위 | 플레이어 몸통 중심 반경 150px, 양방향 |
| 피해 | 직접 50 + 적별 내상 중첩 × 15의 내부 피해 |
| 일반 공격 무적 | 시작 후 `[0.10, 0.45)`초 |
| 수전증 | 정상 종료 또는 중단 시점부터 4초 |

범위는 적 피격 상자와 원의 교차로 검사하고 지형 차폐가 있으면 피해를 주지 않는다. 월식에는 과열 배율을 적용하지 않는다. 유효한 대상의 내상만 폭발·소모하며 내상 0인 적도 직접 피해를 받는다. 보스 posture는 올리지 않는다.

시작 비용과 쿨다운은 빗나감·피격·사망으로 반환하지 않는다. 무적 전후에는 피격으로 중단될 수 있으며 0.30초 폭발 전 중단되면 피해가 발생하지 않는다. 발동 시각과 맞은 시각이 같으면 13장의 이벤트 우선순위에 따라 피격을 먼저 처리한다. 이미 발행한 폭발 이벤트는 다시 발행하지 않는다.

수전증 동안 강화 만월과 월식만 금지한다. 기본 3연타의 만월, 이동, 2단 점프, 대시와 패링은 모두 가능하다. 손 떨림 연출로 표현하고 입력 자체를 무작위로 흔들지 않는다. 설정의 사흘 후유증은 서사 표현이며 게임 시간 3일 동안 능력을 봉쇄하지 않는다.

## 11 방심 상태

방심은 핵심 전투 완료 후 구현하는 확장 기능이다. 첫 전투 구현에서는 기본 비활성화하고 플래그로 켠다.

서방 일반 적은 `unaware_of_palm=true`로 생성 가능하다. 처음 피해를 받은 지상 초승은 내상을 +1 추가하고 일반 적에게 0.35초 경직을 준다. 반격 초승과 합산해도 최대 3중첩이다. 보스는 기본 false이고 이 기능으로 강제 경직시키지 않는다.

장법 피해를 직접 받거나, 시야 안의 240px 이내에서 다른 적이 장법 피해를 받는 것을 목격하면 경계 상태로 영구 전환한다. 동일 틱에 여럿을 맞히면 공격 시작 시점의 대상별 방심 여부를 사용하고 피해 처리 후 목격 이벤트를 전파한다. 사망 후 재생성 시만 초기화한다.

## 12 데이터와 책임 분리

추가 파일명은 제안이며 같은 책임이 유지되면 프로젝트 관례에 맞춰 변경할 수 있다. 거대한 player.gd 조건문에 모든 전투를 넣지 않는다.

| 데이터 또는 모듈 | 책임 |
|---|---|
| PlayerCombatConfig Resource | HP, 시간 창, 자원, 마열, 내상, 배율 등 조정값 |
| AttackData Resource | 공격 피해·시간·사거리·태그·내상 부여/폭발·패링 분류 |
| AttackInstance | 공격 1회 식별자, 시작 시 확정 수치, 이미 처리한 대상 집합 |
| HitEvent | 공격자·대상, attack_instance_id, hit_id, origin, 피해, knockback, hitstun, parry_class, posture_damage, 무적 무시 여부 |
| CombatResolver | 적격 여부 → 무적 → 패링 → 피해 → 상태·보상 단일 처리 |
| EnemyStatus | HP, armor_rate, 내상 중첩/만료, posture, 기절/면역, 방심 |
| Player 상태 | 행동, 행동 시간, HP, 내공, 마열/침식, 수전증, 게이지, 공중 재도약, 반격, 보호 시간 |

공격 중복 방지는 `(attack_instance_id, hit_id, target_instance_id)`를 키로 한다. 현재 `_struck`의 그룹 순번 저장은 노드 삭제·추가 시 다른 적과 혼동할 수 있으므로 안정적인 인스턴스 ID 또는 유효한 객체 참조로 교체한다. 공격이 종료되면 해당 기록을 정리한다. 다단 히트는 공격 인스턴스가 같아도 hit_id가 다르다.

일반 적·보스·허수아비는 같은 resolve_hit 결과 구조를 받는다. `take_hit(facing, kick, damage)`는 결과를 적용하는 호환 래퍼로 남기거나 점진적으로 교체한다. 피해 숫자·누적 damage 통계는 원시 피해 대신 실제 적용 피해를 사용한다. 유효 HP를 넘는 피해는 HP 감소량만 통계에 더한다.

권장 결과 필드: result_kind(IGNORED/INVULNERABLE/NORMAL/PARTIAL/PERFECT), hp_damage, internal_damage, injury_before, injury_after, posture_added, caused_stagger, killed. 자원·보상 처리는 이 결과의 단 한 지점에서 실행한다.

## 13 물리 틱과 시간 처리

게임플레이 시간은 물리 dt를 사용한다. 히트스톱 중 이동·중력·공격·패링 창·재사용·내상 만료·posture 감소·내공 회복·마열 감소·보호·수전증을 모두 정지한다. 히트스톱 자체의 해제 타이머는 기존 Juice 방식으로 실제 시간을 사용해 종료한다.

한 틱은 아래 순서로 처리한다.

1. 입력 이벤트를 수집한다. 히트스톱이면 요청만 저장하고 전투 시뮬레이션을 끝낸다.
2. 직전 틱 이후 만료된 시간 제한 상태를 정리하고 입력 우선순위에 따라 상태를 시작한다.
3. 플레이어·적의 이동과 충돌을 갱신하고, 현재 틱의 타격 후보를 수집한다.
4. 적→플레이어 피해를 먼저 해결한다. 같은 시각은 attack_instance_id 순서다.
5. 피격으로 취소되지 않은 플레이어→적 피해를 해결한다. 보스 기절로 취소된 근접 타격도 제거한다.
6. 착지를 반영하고 착지 버퍼 점프를 한 번 평가한다. 타이머·자원은 틱당 한 번만 갱신한다.
7. 결과 이벤트로 HUD·이펙트·히트스톱 요청을 출력한다. 이번 틱을 완료한 뒤 다음 틱부터 동결한다.

전투 시각은 단조 증가하는 combat_time 또는 동등한 누적 초로 통일한다. 새 상태 시작과 같은 틱의 피격은 경과 0으로 판정한다. 부동소수점 경계는 공통 비교 함수/정수 물리 틱 환산 등 한 방식으로 통일해 12틱째 경계를 테스트한다. 서로 다른 노드의 _physics_process 실행 순서에 피해 우선순위를 맡기지 않는다.

히트스톱 요청 여러 개는 합산하지 않고 가장 긴 남은 시간만 취한다. 완전 패링 연출 히트스톱은 0.06초, 부분은 0.025초다. 죽은 공격자는 이미 발사된 독립 투사체를 제외하고 새 타격을 생성하지 않는다.

### 패링 판단 의사 코드

```text
resolve_incoming(hit, player):
    if already_resolved(hit, player) or player.dead:
        return IGNORED
    mark_resolved(hit, player)
    if protected_from(hit):
        return INVULNERABLE

    eligible = player.action == PARRY
        and is_in_front(hit.incoming_origin, player.parry_facing)
        and hit.parry_class != UNPARRYABLE

    if eligible and 0 <= elapsed < 0.100:
        enter_success_recovery(0.10)
        set_protection(0.06)
        grant_perfect_rewards_once()
        apply_attacker_posture_once(hit.posture_damage)
        return PERFECT with hp_damage = 0

    if eligible and 0.100 <= elapsed < 0.250
        and hit.parry_class == NORMAL:
        damage = round_positive(normal_damage(hit) * 0.30)
        apply_damage_and_status(damage, hit.status_effects)
        if alive:
            enter_success_recovery(0.18)
            set_protection(0.12)
            apply_knockback(hit.knockback * 0.25)
        return PARTIAL

    apply_normal_hit_or_death(hit)
    return NORMAL
```

## 14 HUD와 신규 에셋

HUD에는 HP, 내공, 마열과 침식 경고, 월식 게이지, 수전증 남은 시간을 표시한다. 보스 HUD는 HP 아래에 채워지는 기절 게이지를 별도로 표시한다. 적의 내상은 몸통 주변 작은 검붉은 표식 최대 3개로 보여준다. 숫자·아이콘을 함께 사용해 색상만으로 상태를 구별하지 않는다.

완전 패링은 흰 중심 섬광과 검붉은 원, 날카로운 타격음, 짧은 정지로 표시한다. 부분 패링은 작은 붉은 파편, 둔한 소리, 실제 받은 피해 숫자를 표시한다. 실패에는 성공 이펙트를 내지 않는다. 디버그 HUD에 PERFECT/PARTIAL/MISS, 경과 시간, incoming hit_id와 posture 증가량을 출력한다.

필요 신규 클립은 패링 자세·완전 성공·부분 성공·피격·사망·월식이다. 2단 점프와 수전증은 별도 효과로 먼저 구현할 수 있다. 그림 미납 상태에서는 기존 포즈와 디버그 효과를 임시 연결하되 논리를 애니메이션 존재 여부에 의존시키지 않는다. 기존의 코드 스쿼시·스트레치 금지, manifest 슬롯 관리 원칙을 유지한다.

## 15 초기화와 생명주기

R 초기화는 플레이어 위치·속도·바라보는 방향·기존 콤보 변수뿐 아니라 HP 100, 내공 100, 마열 0, 침식 false, 게이지 0, 수전증 0, 월식/대시 쿨다운 0, 모든 보호·버퍼·반격·예약·행동 타이머를 초기화한다. 공중 재도약은 true, 코요테는 실제 바닥 상태에 맞춰 설정한다.

훈련장의 모든 적도 HP·내상·posture·기절·피격 기록을 초기화하고 남은 공격 판정·투사체·장판·히트스톱을 정리한다. 플레이어가 죽으면 공격·패링·회복이 멈추고 사망 포즈를 표시한다. 적의 사망 후 재생성에는 이전 인스턴스의 내상이나 공격 ID 기록이 남지 않아야 한다.

## 16 구현 순서와 완료 기준

### 단계 1 방어가 가능한 플레이어

Space 입력 분리 → 플레이어 HP/피격/사망 → 공통 HitEvent/피격 처리 → 패링 시간 창 → 공격 훈련 적 → 보스 posture 순서로 구현한다. 훈련 적은 NORMAL 단타, NORMAL 3연타(타격 간격 0.35초), PERFECT_ONLY 내려찍기, UNPARRYABLE 장판을 선택 실행할 수 있어야 한다. 이 단계부터 직접 공격을 받고 부분·완전 패링을 구분할 수 있어야 한다.

### 단계 2 핵심 장법과 경공

2단 점프 → 기존 공격 내상 부여 → 기본 만월 폭발 → 완전 패링 반격 → 대시 무적을 적용한다. 기존 애니메이션과 이동 수치를 보존하며 정상 전투 흐름을 확인한다.

### 단계 3 자원과 절초

내공/마열 → 강화 만월 → 월식/수전증 → HUD와 효과를 연결한다. 방심은 이 단계 완료 후 옵션으로 추가한다.

### 검증 시나리오

아래는 구현자가 자동 검증과 수동 플레이로 확인할 수락 조건이다. 현재 실행 완료를 의미하지 않는다. 기존 `--selftest`도 유지하고 필요하면 `--combat-selftest`를 별도로 추가한다.

기존 selftest의 피해 통계는 내상 도입 후 바뀔 수 있으므로 옛 총 피해값을 그대로 정답으로 고정하지 않는다. 기존 5회 명중 조건과 공중/하단 공격 동작을 보존하면서 신규 내상 결과를 별도 검증한다.

## 17 Claude 구현 착수 지시

이 문서와 godot/README.md를 읽고 godot/ 프로젝트에 단계 순서대로 구현한다. 기존 이동과 공격 클립을 유지하며 Space는 패링 전용, W는 점프로 분리한다. 가장 먼저 공격 가능한 훈련 적을 만들어 부분 패링 70% 감소와 완전 패링 피해 0·보스 posture 증가를 실제 전투에서 검증한다. 신규 수치는 Resource나 공통 설정으로 분리한다. 각 단계가 끝나면 관련 수락 조건을 검증하고 godot/README.md 조작 설명을 갱신한다. 최종 보고에는 변경 파일, 구현한 단계, 통과한 검증, 미납 에셋과 남은 항목을 적는다.
