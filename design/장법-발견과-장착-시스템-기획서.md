# 장법 발견과 장착 시스템 기획서

> 2026-10-21 개편: 전투 동작·장법별 수치·이펙트·4번 획득 연출은 [장법 4종 전투 로직과 시각 차별화 개편안](../../문서/기획/장법-4종-전투로직과-시각차별화-개편안.md)을 우선 적용한다. 1~3번은 동급 선택, 4번은 강한 후반 보상이다. 현 본편의 강화 입력은 E이고 우클릭/F는 월인이다. 아래의 발견·영구 습득·장착·저장 규칙은 유지한다.

작성일: 2026-10-20  
대상: 본편 탐사·플레이어 전투 확장  
범위: 기획과 구현 지침. 게임 코드·에셋 변경은 포함하지 않는다.

## 1. 핵심 구조

**맵에서 장법 비급을 발견하고, 장법 하나를 장착해 좌클릭 3연계와 강화 초식을 함께 바꾼다.**

새 장법은 공격력 상승 보상보다 싸우는 방식의 선택이다. 기본 흑월장은 균형, 쇄진장은 직선 돌파, 회란장은 다수전, 투골장은 내상 집중에 강점을 갖는다. 기본 흑월장만으로도 본편의 모든 필수 전투와 이동을 완료할 수 있다.

첫 장의 범위는 기본 1종과 발견 3종이다. 장법별 레벨·희귀도·랜덤 옵션·초식 개별 조합은 도입하지 않는다. 한 비급을 얻으면 해당 장법의 기본 연계와 강화 초식을 모두 사용할 수 있다.

### 현재 입력과 제안의 연결

2026-10-20 로컬 코드에서 좌클릭/J/X는 기본 3연계, 우클릭/E는 강화 만월이다. 사용자가 말한 공격 교체 의도는 **주공격 슬롯 전체를 교체하는 시스템**으로 반영한다.

| 입력 | 장착 후 기능 |
|---|---|
| 좌클릭 / J / X | 장착 장법의 기본 3연계 |
| 우클릭 / E | 장착 장법의 강화 초식 |
| Space | 기존 부분·완전 패링 |
| Shift | 기존 잔월보 |
| W | 기존 점프·2단 점프 |
| Q | 기존 월식 |
| Tab — 신규 제안 | 장법 목록과 설명 열기 |

모바일은 기존 장법·강화 버튼이 장착 내용을 사용하고, 메뉴 안에 장법 목록 진입 버튼을 둔다. 새로운 전투 버튼을 늘리지 않는다.

## 2. 세계관 연결

흑월장·무간심법·잔월보·월식은 위지란의 고유 무공으로 유지한다. 다른 장법을 장착해도 무간심법으로 내공을 운용하고 검붉은 장력을 사용한다. 월식은 장착 장법과 무관하게 흑월장의 절초로 사용한다.

비급은 남의 내공을 즉시 얻는 물건이 아니라 **장력의 운용·타격 궤도·발경법을 기록한 문서**다. 이미 초절정인 위지란이 다른 장법의 원리를 자신의 무공에 적용한다는 설정을 제안한다.

쇄진장·회란장·투골장과 해당 비급의 내력은 이번에 추가한 제안이다. 기존 설정집에 있는 무공으로 간주하지 않는다. 서방 보스를 쓰러뜨려 서방 마법을 그대로 장법으로 얻는 구조는 사용하지 않는다.

## 3. 발견에서 사용까지

`탐사 단서 → 선택 경로 → 비급 발견 → 영구 습득 → 안전 지점에서 장착 → 시험 타격`

1. 부서진 장흔, 풍문, 빼앗긴 무공 기록 등으로 비급이 있는 방향을 알린다.
2. 기존 이동 능력과 전투를 활용하는 짧은 선택 경로 끝에 비급을 둔다.
3. 상호작용하면 이름·역할·대표 동작·새 장법 알림을 표시한다. 자동 장착하지 않는다.
4. 장법 목록에 즉시 등록하고 습득 상태를 저장한다.
5. 가까운 안전 지점에서 비교 후 장착할 수 있다.
6. 안전 지점의 목각 표적으로 기본 연계와 강화 초식을 시험한다.

첫 비급은 주 경로에서 갈림길이 보이게 배치한다. 이후 비급은 짧은 우회 탐사를 요구하되 보스 클리어로 길을 영구 폐쇄하지 않는다.

### 습득과 저장

- 비급은 고정 배치·확정 획득이며 랜덤 드롭이 아니다.
- 한 번 습득한 비급은 사망해도 유지한다. 체크포인트 위치는 이동하지 않는다.
- 습득 즉시 비급 ID와 획득 장소 ID를 함께 저장한다. 저장된 비급은 재진입 시 비활성화한다.
- 비급 보상과 해당 장소의 적 처치는 별도 상태다. 사망하면 적은 체크포인트 규칙에 따라 재등장할 수 있지만 비급은 중복 지급하지 않는다.
- 습득 중에는 공격을 계속 받는 긴 창을 띄우지 않는다. 상호작용은 주변 전투가 끝난 뒤 허용하고, 짧은 알림 이후 상세 설명은 메뉴에서 읽게 한다.

## 4. 장착 규칙

**장착 슬롯은 1개다.** 기본 연계의 1타·2타·3타와 강화 초식을 묶어서 교체한다. 예를 들어 쇄진장 1타와 투골장 강화 초식을 섞을 수 없다.

- 장법 메뉴는 전투 중에도 설명을 확인할 수 있으나, 장착은 연무장·휴식 지점·보스 앞 체크포인트에서만 가능하다.
- 싱글플레이 메뉴를 열면 적·투사체·플레이어·상태 타이머를 함께 일시정지한다. 히트스톱과 별개의 메뉴 일시정지를 사용한다.
- 장착은 플레이어가 지상 중립 상태이고 주변 전투가 종료되었을 때 허용한다. 공격·피격·대시·월식·사망 처리 중에는 불가하다.
- 장착 시 콤보 진행, 콤보 입력 유예, 예약 입력, 패링 반격 대기만 초기화한다.
- 체력·내공·마열·월식 충전·쿨다운·수전증은 장착으로 회복하거나 초기화하지 않는다.
- 장착 상태는 즉시 저장한다. 보스 입구에서 장법을 바꾸면 그 선택을 재도전에도 유지한다.
- 보스 재시도의 체력·전투 자원 복원은 기존 체크포인트 정책을 따른다. 장법 변경이 체크포인트 자원 스냅샷을 다시 찍는 계기가 되지는 않는다.
- 기존 세이브에 장법 정보가 없거나 장착 ID가 유효하지 않으면 흑월장으로 복원한다.

쌍등객잔에서는 목록 확인과 장착은 가능하지만 공격 연습은 하지 않는다. 목각 표적은 연무장과 야외 안전 지점에만 둔다.

## 5. 첫 장의 장법 네 종류

### 흑월장 黑月掌

**역할:** 범용·입문. 현재 전투의 기준점.

| 행동 | 기능 |
|---|---|
| 초승 | 전방으로 짧게 접근하며 타격, 내상 축적 |
| 반월 | 주위의 적을 휘감는 범위 타격, 내상 축적 |
| 만월 | 전방 발경, 내상 폭발 |
| 강화 만월 | 내공을 사용하는 강한 발경과 내상 폭발 |

현재 구현을 그대로 장법 데이터의 첫 항목으로 옮긴다. 초기 시스템 전환 과정에서 위력·범위·속도를 동시에 재조정하지 않는다.

**강점:** 방향과 적 수가 자주 바뀌는 전투에 안정적이다.  
**약점:** 다른 장법의 전문 영역에서는 효율이 낮다.  
**획득:** 처음부터 보유.

### 쇄진장 碎陣掌

**역할:** 직선 돌파. 원거리 적에게 닿는 데 유리하고 좁은 전방에 집중한다.

| 행동 | 기능 |
|---|---|
| 1타 진입장 | 흑월장보다 긴 직선 전진 타격, 내상 1 |
| 2타 쐐기장 | 좁은 전방 연속 압박, 판정은 1회, 내상 1 |
| 3타 파진장 | 전방 발경과 내상 폭발, 뒤쪽 판정 없음 |
| 강화 관진 | 준비 동작 뒤 더 멀리 전진하며 1회 타격·내상 폭발 |

- 공격 전진에는 무적을 부여하지 않는다. 패링·대시와 구별한다.
- 벽과 낙하 위험 지형 앞에서 전진을 멈춘다. 맵 이동 능력의 필수 해법으로 사용하지 않는다.
- 고속 이동 구간은 이동 전후를 잇는 충돌 검사로 적을 놓치지 않게 한다.
- 일반 적은 밀 수 있지만 보스의 위치는 강제로 이동시키지 않는다.
- 강화 초식 종료 후 빈틈은 강화 만월보다 길게 잡는다.

**장점:** 궁수 접근과 한쪽 방향 돌파.  
**대가:** 후방에 취약하고 잘못 들어가면 피격 위험이 높다.  
**획득 제안:** F1 불탄 수림길의 무너진 동방 초소. 기존 2단 점프와 공중 대시로 들어가는 짧은 옆길 끝의 회수된 비급. 티아넬 전에 발견 가능.

### 회란장 回瀾掌

**역할:** 다수전. 넓게 때리고 적 사이에서 빠져나올 공간을 만든다.

| 행동 | 기능 |
|---|---|
| 1타 개장 | 짧은 전방 호형 타격, 내상 1 |
| 2타 환장 | 몸 주변 원형 타격, 내상 1 |
| 3타 퇴조 | 넓은 원형 발경과 내상 폭발, 일반 적을 바깥으로 밀기 |
| 강화 회란 | 준비 뒤 큰 원형 발경, 범위 안의 적마다 1회 타격·내상 폭발 |

- 회전 이펙트가 여러 번 보여도 적 1명당 1회만 명중한다.
- 적을 벽에 계속 묶는 연속 경직·지속 흡입은 도입하지 않는다.
- 보스에게 넉백을 적용하지 않는다.
- 넓은 범위의 대가로 단일 대상 직접 피해와 내상 폭발 계수를 낮춘다.

**장점:** 둘러싸인 전투, 근접 졸개 묶음 처리.  
**대가:** 적을 밀어내므로 다음 공격을 이어가기 어렵고 보스 단일 화력은 낮다.  
**획득 제안:** F2 단층 임시 연구소의 압수품 보관실. 주 경로에서 보이는 별도 잠금장치를 지키는 소규모 적을 처치하면 확보한다. 열쇠 랜덤 드롭은 없다.

### 투골장 透骨掌

**역할:** 단일 대상·내상 집중. 짧은 거리를 유지하며 기회를 기다린다.

| 행동 | 기능 |
|---|---|
| 1타 점장 | 짧은 정면 타격, 내상 1 |
| 2타 첩장 | 한 대상에 집중하는 정면 타격, 내상 2 |
| 3타 침장 | 직접 피해는 작고 내상 폭발 계수가 큰 발경 |
| 강화 투골 | 긴 준비 뒤 단일 대상 강한 내상 폭발 |

- 2타의 내상 2는 공통 최대 3을 넘기지 않는다.
- 각 타격은 전방 범위 안 가장 가까운 적 하나를 선택한다. 벽 뒤 대상은 제외한다.
- 선택은 타격 발생 시점에 수행한다. 준비 중 이동한 적을 자동 추적하거나 뒤돌아서 맞히지 않는다.
- 사거리가 짧고 공격 전진이 작다. 빠르게 도망가는 적에게는 불리하다.
- 내상이 없는 적에게 강화 투골을 쓰면 효율이 낮다. 스택 없이 사용하는 입력 자체를 금지하지는 않는다.

**장점:** 가까이 붙어 싸울 수 있는 중장갑 단일 적, 기절한 보스.  
**대가:** 다수전·거리 변화에 약하며 준비 중 공격받기 쉽다.  
**획득 제안:** F3 백향 이송로의 버려진 압수품 수레. 주 경로에서 갈라지는 옛 호송길 끝에서 발견한다.

엘로디의 정화는 내상 폭발을 약화시키므로 투골장이 엘로디의 정답은 아니다. 비급 설명에서 이 단점을 미리 알리고 흑월장 등으로 바꿀 기회를 준다.

## 6. 초기 밸런스 기준

다음 값은 **첫 프로토타입용 상대 목표**다. 확정 프레임·피해 수치는 기존 흑월장의 실측을 기준으로 후속 조정한다.

| 항목 | 흑월장 | 쇄진장 | 회란장 | 투골장 |
|---|---|---|---|---|
| 기본 연계 총 직접 피해 목표 | 100% | 95% | 75% | 65% |
| 3타 내상 폭발 계수 | 기존 8 | 8 | 6 | 12 |
| 강화 내상 폭발 계수 | 기존 12 | 12 | 9 | 18 |
| 강화 직접 피해 목표 | 기존 42 | 42 | 32 | 25 |
| 강화 내공 비용 | 25 | 30 | 30 | 30 |
| 강화 마열 증가 | 30 | 30 | 30 | 35 |
| 연계 소요 시간 목표 | 기존 | 기존의 105% | 기존의 110% | 기존의 115% |
| 전방 도달 능력 | 보통 | 높음 | 낮음 | 낮음 |

총 직접 피해는 1~3타 합계이며 내상 폭발 피해는 별도다. 실제 DPS는 공격 시간·명중 수·내상 준비·후딜을 포함해 비교한다. 표의 비율을 각 타에 일괄 곱하지 말고 초식별로 배분한다.

- 기본 공격은 모든 장법에서 내공을 소비하지 않는다.
- 강화 공격은 기존처럼 지상 중립 상태에서 사용하며 공중·앉기·수전증 중에는 사용하지 않는다.
- 장법마다 무적·패링 시간·이동 속도를 보너스로 붙이지 않는다.
- 기본 1·2타는 내상을 부여하고 3타·강화는 소비한다. 별도 표기가 없으면 부여량은 1이다.
- 한 대상에 대한 폭발은 소비 직전 스택 수를 읽고 한 번만 계산한 뒤 스택을 제거한다.
- 과열·침식·수전증·방어력 계산은 공통 전투 규칙을 따른다. 새 장법마다 별도 자원 체계를 만들지 않는다.
- 월식은 모든 장법에서 동일한 피해·내상 소비·비용·충전 규칙을 사용한다.

### 반격과 게이지

완전 패링 뒤 반격 기회는 모든 장법에서 유지한다. 다음 기본 1타를 강화하며, 현재 반격의 내상 2·전진 보정 등 공통 효과를 적용한다. 내상 2는 일반 부여량에 더하는 것이 아니라 대체값으로 처리한다.

반격 자격은 `초승 데이터와 동일한가`가 아니라 `기본 연계의 첫 타인가`로 판정한다. 이후 계수는 장법별로 중복 적용하지 않는다.

월식 게이지는 기존처럼 공격 1회에서 정해진 상한만 얻는다. 회란장으로 4명을 때렸다고 공격당 게이지를 4배 지급하지 않는다.

## 7. 장법 화면

왼쪽에는 보유 장법, 오른쪽에는 선택한 장법의 설명과 공격 미리보기를 배치한다.

반드시 보여줄 정보:

- 장법 이름과 한 문장 역할.
- 기본 3연계와 강화 초식의 짧은 설명.
- 범위·전진·단일 대상·다수전 특성.
- 강화 내공 비용과 마열 증가.
- 장점 1개, 주의점 1개.
- 현재 장착 표시와 장착 버튼.
- 안전 지점 밖이라면 “휴식 지점에서 장착할 수 있습니다” 표시.

단일 종합 전투력 점수나 초록색 상승 화살표로 우열을 매기지 않는다. 발견하지 않은 장법은 이름과 위치를 공개하지 않고 미발견 항목으로 표시한다.

HUD는 현재 장법 아이콘과 이름을 작게 표시한다. 강화 버튼의 이름·아이콘·내공 부족 표시는 장착 장법과 함께 갱신한다.

처음 비급을 얻으면 “장법을 발견했습니다. 다음 휴식 지점에서 장착할 수 있습니다” 안내를 한 번 표시한다. 보스 앞 체크포인트에 도착했을 때 새 장법이 있으면 메뉴에 알림 점을 붙인다.

## 8. 본편 맵 반영

| 기존 맵 | 추가 요소 | 추가 제작 범위 |
|---|---|---|
| T0 천흑산 연무장 | 흑월장 장착 상태 확인, 장법 메뉴 안내 | 메뉴 진입 안내 |
| F1 불탄 수림길 | 쇄진장 비급 옆길 | 짧은 이동 구역 1개 |
| B1 티아넬 입구 | 장착·시험 표적 | 기존 쉼터에 통합 |
| F2 단층 임시 연구소 | 회란장 압수품 보관실 | 선택 전투 구역 1개 |
| B2 미레유 입구 | 장착·시험 표적 | 기존 쉼터에 통합 |
| F3 백향 이송로 | 투골장 수레와 옛길 | 선택 전투 구역 1개 |
| B3 엘로디 입구 | 장착·시험 표적 | 기존 쉼터에 통합 |
| H0 쌍등객잔 | 장법 열람·장착 | 비전투 메뉴만 |

각 선택 경로의 목표 소요 시간은 2~4분이다. 기존 첫 장 분량에 모두 포함하면 약 6~12분이 늘어날 수 있으므로 전체 플레이 시간은 제작 후 다시 측정한다.

보스 처치 후에는 해당 장의 휴식 지점 간 귀환을 제공해 놓친 비급을 회수할 수 있게 한다. 최소 구현은 체크포인트 메뉴의 구역 선택이며 자유로운 월드 텔레포트까지 요구하지 않는다. 귀환은 새 구역을 선행 해금하지 않는다.

## 9. 구현 구조

기존 `CombatResolver`와 `EnemyStatus`를 공통 피해·내상 처리 경로로 유지한다. 장법마다 별도 플레이어 스크립트를 만들지 않는다.

### 데이터 분리

`PalmStyleData`에 다음 정보를 둔다.

| 필드 | 의미 |
|---|---|
| `id` | 변경하지 않는 저장용 ID |
| `display_name`, `description`, `icon` | 메뉴 표시 |
| `light_attacks[3]` | 기본 연계 초식 데이터 |
| `heavy_attack` | 강화 초식 데이터 |
| `unlock_source_id` | 발견 장소 연결 |

`PalmAttackData`에는 피해·범위·방향·준비·활성·회수 시간, 이동량, 대상 수, 내상 부여량·폭발 계수, 내공·마열 비용, 효과·애니메이션 참조를 둔다.

특히 `is_heavy`, `combo_index`, `counter_eligible`, `injury_mode`를 명시한다. 현재 코드의 `a == THRUST`, `a != HEAVY` 같은 특정 딕셔너리 비교를 의미 기반 판정으로 교체해야 새 장법에서도 반격과 과열이 정상 동작한다.

### 실행 순서

1. 입력을 받아 현재 상태와 장착 장법의 초식을 조회한다.
2. 강화라면 지상·수전증·내공 조건을 검사한다.
3. 공격 시작 가능 여부가 확정되면 장법 ID·초식 데이터·과열 배율·침식 후딜을 해당 공격에 고정한다.
4. 내공 차감과 마열 증가는 공격 시작 때 한 번만 처리한다. 빗나가거나 취소되어도 돌려주지 않는다.
5. 활성 구간에 범위를 검사하고 공통 resolver로 결과를 전달한다.
6. 공격 인스턴스와 대상 ID로 중복 명중을 방지한다.
7. 회수와 콤보 유예를 적용하고 다음 입력을 기다린다.

장착 중인 데이터를 공격 도중 다시 읽어 효과를 바꾸지 않는다. 이동 타격은 실제 이동 경로에서 충돌을 검사하며 시각 이펙트 크기와 판정 범위를 일치시킨다.

### 저장 예시

```json
{
  "palm_system_version": 1,
  "unlocked_palm_ids": ["black_moon", "formation_breaker"],
  "equipped_palm_id": "formation_breaker",
  "collected_manual_ids": ["f1_outpost_manual"]
}
```

알 수 없는 ID는 실행 데이터로 사용하지 않는다. 복구 시 흑월장 보유를 보장하고, 보유하지 않은 장법을 장착 상태로 허용하지 않는다. 저장은 기존 저장 서비스에 통합하며 비급 전용으로 플레이어 진행을 따로 덮어쓰지 않는다.

## 10. 제작과 검증 순서

1. 기존 흑월장을 데이터 구조로 이동하고 공격·패링·월식의 기존 결과가 유지되는지 확인한다.
2. 쇄진장 1종과 임시 비급 1개로 발견·저장·장착·HUD·재도전을 연결한다.
3. F1 선택 경로와 티아넬 접근 전투에서 장법 차이를 검증한다.
4. 회란장과 투골장을 추가하고 내상·게이지 중복 처리를 검사한다.
5. 검증된 판정에 맞춰 장법별 애니메이션·이펙트를 발주한다.

### 완료 판정

- 비급 획득 후 사망·재실행해도 습득 상태 유지.
- 동일 비급을 다시 획득하거나 중복 보상받지 않음.
- 안전 지점 밖·공격 중에는 장착 불가.
- 장법 변경으로 내공·마열·월식 쿨다운·수전증이 초기화되지 않음.
- 좌클릭 연계, 우클릭/E, 모바일 버튼, HUD가 동일한 장착 데이터를 사용.
- 새 장법에서도 완전 패링 후 첫 타 반격이 정상 작동.
- 회란장 다중 명중이 게이지를 적 수만큼 중복 지급하지 않음.
- 투골장 내상이 3을 넘지 않고, 폭발이 한 번만 소비됨.
- 쇄진장 이동 공격이 벽을 통과하거나 적을 건너뛰어 판정하지 않음.
- 어떤 장법을 장착해도 기존 대시·2단 점프·Space 패링·Q 월식 유지.
- 모든 필수 보스는 흑월장만으로도 공략 가능.
- 기본값만 있는 이전 세이브가 흑월장으로 정상 진입.
