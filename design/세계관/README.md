# 세계관 — 합벽(가제)
액션게임의 배경 세계 정리. 원본은 크랙 프로젝트 「합벽 세계·인물 설정집 초안」(3차 개정, 2026-10-19). 설정이 바뀌면 이 폴더도 같이 고친다.

## 한 줄
세 해 전, 동쪽의 천하와 서쪽의 대륙이 맞붙었다. 내공과 검의 사람들과 갑주와 마법의 사람들이, 말도 통하지 않는 채 서로의 땅을 베고 있다.

## 핵심 축 — 읽히지 않는 힘
동방의 기(氣)와 서방의 마나는 서로에게 감지되지 않는다. 상대의 강함은 드러나는 순간에야 안다.
